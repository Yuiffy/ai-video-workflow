# 2026-10-07 用户审片复盘

用户指出：缺少救小饼干的开头；救场位置错乱；断桥始终在背景，人物像在岸边支撑另一处坍塌。重新核对 production-plan.json、bridge.png 与 02/05/07 的原片取帧，意见成立。

## 原因与证据

1. **剧本缺失可见的因果。** 01 中三人还在家，02 仅在提示词里说“七海去接饼干岁，现在被困”，没有拍出小饼干如何来到桥上、何时出事、七海为何追过去、退路怎样断掉。01 还让家中的两人同时听见断裂声，再跳到“同一晚稍后”七海遇险，时间关系也不顺。提示词里的背景说明不是观众可见的叙事。
2. **场景参考没有满足行动要求。** bridge.png 实际是从岸边看整座断桥：宽阔的安全步道在前景，桥在中后景，两端又各自有通向岸边的结构。没有角色标位、明确孤立的桥段、桥面高度关系或被堵的退路。我按光影好看放行了这张图，没有按“为什么困住、站在哪、怎么救”验收。
3. **提示词改变了危险对象。** 04 说跨桥面断口；05 改成举手接住顶棚钢梁；07 又同时保留护盾、搭光桥、跑过、顶棚落水。桥面断裂与顶棚下落可以共存，但没有任何镜头建立两者的结构关系。最终护盾像岸边的金色雨伞，断桥留在远处。
4. **引用稳定了外观，没有稳定调度。** 多个视频各自引用人物定妆与同一张环境远景，没有经检查的人物合成起始画面，也没有承接上一镜的具体站位与桥损坏状态。“东岸/西端”只写在文字里，没有映射到固定机位。模型沿用参考图构图的解释与结果相符，但未经对照实验，不能当作已证明的唯一模型内部原因。
5. **生成和审片顺序不当。** 六个动作段在第一个危机场景尚未验证时一起提交。看到空间错误后，采用删重复人物、镜像去程、截掉天台远景等局部剪辑；这些处理没有重建空间。我知道剧本，容易替画面补全因果。文件可解码、对白可识别、人物不变脸，都不足以证明救援戏成立。

## 重做应采用的约束

- 先画完整因果分镜：正常过桥 → 饼干岁落在桥中段 → 七海回身接它 → 身后接缝断开、退路消失 → 岁己在安全端看见 → 能力托住他们脚下的桥板 → 跨回安全端 → 原桥板落水。原因和结果都要有可见动作。
- 先固定一张空间图和一个主机位：左侧安全桥台、右侧悬空桥板、中间缺口、下方河面；七海和饼干岁在右侧板上，岁己在左侧。危险板上的栏杆缺口等特征跨镜保留。
- 简化为桥面下坠这一条危险。金色支撑明确位于桥板下方，与板接触，向上托住；不再添加没有铺垫的头顶坍塌和第二座光桥。
- 新参考图优先补“同一场景中的人物站位与结构关系”：事前建立镜头、断裂后受困画面、能力承重点、撤离后画面。不是增加更多漂亮空景或无约束的多角度图。
- 先验证单镜起始画面的空间，再生成一个主要动作。连续镜头可用上一镜经检查的末帧；切机位时用同一空间关系下的新关键帧，不盲目接末帧，也不把所有图无区别地塞进引用。
- 先验证“断裂—受困—托住—撤离”的核心连续段，再扩展其他镜头；不要等整批付费视频完成后才发现共同错误。
- 静音、隐藏剧本检查：能否直接指出谁在哪、哪块结构会掉、为什么不能走、能力碰到了什么、哪一步让人脱险。任一项需要口头补充剧情，镜头就未通过。
