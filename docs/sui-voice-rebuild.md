# 岁己变声模型重制实验

## 目标和判断标准

以跨场次真实录播制作可追溯的数据集，比较旧 suiV2、较新基础模型以及定制训练模型。目标是音色更接近岁己，同时保持吐字、低高音、笑声、气声和快速说话。不能把训练 loss 下降或单一声纹分数上升当作听感胜出，也不能保证模型重现未覆盖的所有声音。

## 本机现状（2026-09-28）

- GPU：RTX 5080，16GB，CUDA 12.8 的 PyTorch 已通过 GPU 运算检查。
- 原模型：RVC v2 / 48k / 带 F0，文件元数据为 `20epoch`。没有发现原始训练日志，不能据此判定收敛。
- 原索引：10,000 个 768 维向量；索引可能聚类压缩，不能据向量数量反推原始训练时长。
- 数据：D 盘近期录播与 E 盘历史归档。首轮从近期素材筛选，优先减少年代、设备和直播音效带来的音色变化。
- 独立实验环境位于 `temp/sui-voice-rebuild/`；现有 RVC 安装与生产配音配置保持原状。

## 调研与当前选型

| 方案 | 适合用途 | 本次判断 |
| --- | --- | --- |
| RVC v2 / Applio | 低延迟麦克风、已有 `.pth + .index` 工作流 | 成熟的兼容方案；Applio 仍以 RVC 为基础，换界面并不能自动改善音色。保留旧模型作对照。 |
| Seed-VC v2 | 离线变声、抑制输入者音色残留 | 已完成定制 CFM 训练；口语相似度改善，但特殊发声音高改变较多，因此仅作为旁白候选。训练后仍需要参考音频。 |
| Seed-VC v1 F0 44.1k | 对旋律和音高控制要求较高的歌声 | 需要单独验证；不能把 v2 的口语效果等同于歌声效果。 |
| TTS 声音克隆 | 从文字直接生成语音 | 不直接替代本次“保留输入内容/发声”的变声需求。 |

## 数据流程

1. 从有源文件和说话人时间戳的完整录播建立来源清单；避开正在写入的录播、不完整拼接、3D 演出和身份不明音频。
2. 按整场直播划分训练与验证；首轮 16 场、1,470 段候选、135.78 分钟，其中 2026-09-24 和 2026-09-25 整场不入训。
3. 只合并同一高置信度说话人且间隔不超过 250ms 的相邻片段；每段保留源路径、时间范围、字幕、文件哈希。
4. HTDemucs 分离背景伴奏；不做变调、共振峰移动或强动态压缩。源音频与分离后音频均保留。
5. 独立 CAM++ 对照现有岁己参考和其他主播参考库。暂定目标相似度 ≥0.60、与第二名差距 ≥0.08；这是实验筛选阈值，不是身份确定证明。
6. 检查有效音量、削波和人声能量占比；拒绝项进入独立目录并记录原因。分离并不能保证去除游戏人声或所有背景音乐。
7. 补选非平稳发声，统计真实 F0 分布并检查音域尾部；字幕中的“哈哈”等只作候选线索，不能直接视为已验证的笑声标签。
8. 用训练数据建立模型；验证素材不进入训练、检索索引或音色参考选择。

## 训练和比较原则

- 先跑短训练验证显存和梯度，再保存多个 checkpoint；根据留出结果选模型，不默认最后一轮最佳。
- 固定同一批外部输入，比较旧 RVC、Seed-VC 基础模型和定制模型；音量一致，保存可试听 WAV。
- 音色相似度、文字保持、音高/清浊音、非语音稳定性分别记录；自重建只能诊断退化，不能替代跨说话人转换测试。
- 声纹筛选与生成模型共享 CAM++ 家族，声纹结果有偏置风险；需要其他指标与人工盲听共同判断。
- 最终交付应包含模型、参考音频、固定依赖/代码版本、转换命令、训练数据清单、验证样例和实际限制。

## 训练结果

Seed-VC 已完成 2,000 步训练，并保存 500/1,000/1,500/2,000 步检查点。采用另一个声纹模型 ERes2NetV2 与 CPU Paraformer 检查，四段既有旁白的探索性结果如下（相似度不是百分比）：

| 模型 | 平均相似度 | 平均字符错误率 |
| --- | ---: | ---: |
| 原 suiV2，+4 | 0.6347 | 8.40% |
| 原 suiV2，不升调 | 0.7077 | 9.69% |
| Seed-VC 基础模型 | 0.6169 | 9.16% |
| Seed-VC 定制 1,000 步 | 0.7379 | 7.58% |
| Seed-VC 定制 1,500 步 | 0.7588 | 9.55% |
| Seed-VC 定制 2,000 步 | 0.7581 | 9.69% |

因此暂选 1,000 步作为旁白的折中候选，而不按最终训练 loss 选 2,000 步。四段样本不足以证明一般性优越，英文专名与 ASR 自身错误也计入 CER；还需要试听。

六条独立按钮声音压力测试显示：在源/输出均有 F0 的帧上，音高变化超过 6 半音的平均比例，旧 RVC 约 1.3%，Seed-VC 1,000 步约 36.7%。这是同一目标声音的重建诊断，不是跨说话人转换成绩；RMVPE 在笑声等非周期声音上也可能有八度错误。不过它已经足以反对“新架构全面更好”的结论，并促使增加显式 F0 的 RVC 训练路线。

追加 RVC 数据包含按钮项目中 108 条、约 7.03 分钟特殊声音，源目录最后相关提交为 `ff8b9352fb91c871a146b74037287dc32a633749`（2025-09-09），与 2026 年验证直播隔开；六条压力测试音频完全排除。按钮目录的人工命名可提供额外身份线索，因此允许较弱的 CAM++ 匹配（≥0.35、领先第二名 ≥-0.10），每条均记录 `catalog_identity_exception`。这不是逐条人工试听通过的声明。特殊音频在 RVC 训练中使用 2 倍采样权重。

RVC 使用独立复制的运行代码、RMVPE、48k F0 预训练模型，先验证单 GPU 训练，再按检查点进行比较。旧安装和 suiV2 文件未修改。最终结果以交付报告为准。

## 最终选型与交付

已完成 RVC 20 轮训练，选用第 10 轮作为主模型 `sui_v3_48k.pth`；这里的 v3 是本次模型命名，底层仍为 RVC v2。完整索引保留 363,011 个 768 维特征向量。清理后的直播与按钮训练音频共约 120.49 分钟。

| 开发验证指标 | 同参数旧 suiV2 | 新 RVC 第 10 轮 |
| --- | ---: | ---: |
| 四段外部 TTS 平均声纹相似度 | 0.7195 | 0.7714 |
| 四段平均字符错误率 | 9.43% | 5.40% |
| 六条特殊声音自重建：音高差 >6 半音比例 | 2.96% | 2.58% |
| 六条特殊声音自重建：清浊音一致率 | 86.66% | 82.65% |

第 5 轮相似度最高，但特殊音大幅音高偏移达到约 12.55%，因此未选；第 15/20 轮没有提高旁白相似度，且文字保持退步。特殊声音并未在所有指标上胜出，不能声称任意发声都稳定。尚无真人盲听、真实使用者跨说话人特殊音回归或实时端到端延迟结论。

完整交付位于 `outputs/sui-voice-20260928/`：模型与索引、两套转换脚本、13 组共 52 条可试听对照、全部清理后训练/验证音频、来源清单、逐条评测、代码与依赖记录、恢复训练状态及中文使用说明。主入口为 [使用说明](../outputs/sui-voice-20260928/README.md) 和 [试听页](../outputs/sui-voice-20260928/listen.html)。

已实际验证两套交付转换脚本；RVC 用原本机环境，Seed-VC 使用 `D:/workspace/fun/SeedVC-Sui-20260928` 的独立环境。数据构建单元测试 2 项通过；训练/验证 ID 和索引来源无交集，压力测试按钮的源文件与哈希不入训，160 条评测 WAV 均能解码且非静音、无非有限数值。模型指标属于选型时使用的开发验证集，不是独立盲测成绩。
