本项目第二版采用同样的观看顺序：

1. 用一个观众好奇的问题开场：为什么一句晚安需要这么多步骤？
2. 先给地图：录播姬 → Webhook → 文件稳定与合并 → ASR → 上下文 → 晚安、漫画、梗概、切片 → 人工确认。
3. 每个节点回答三个问题：输入是什么、用了什么现成工具、输出解决了什么。
4. 再讲真正费心的细节：上下文取舍、Prompt 边界、参考图、模型文字能力、多人配置、发送时机和失败恢复。
5. 用“可重复的工程取舍”收尾，避免把项目说成某个模型一键完成。

这些页面的播放量、时长和简介是当时页面可见信息，不代表内容质量的客观评分。
