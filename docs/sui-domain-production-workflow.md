# 岁己领域动画制作流程

2026-10-15 用户认可「自闭圆顿裹·15秒全彩三角色替换修订」及「自闭圆顿裹·15秒全彩角色重绘修订」。本地原样归档在 `outputs/approved/sui-mahito-20261015/`；manifest 记录 SHA256、角色/动作引用、原始提示词、生成身份及技术检查。素材不提交到公开仓库。

## 已验证的制作方法

1. 从动作原片选取连续片段，保留原速、剪辑时间、机位和关键手势。自闭圆顿裹采用原片 22–37 秒，15 秒、24 fps、360 帧。先逐镜头检查，标出角色位置及动作区域。
2. 动作参考与角色身份分开。角色图片依次是岁己、栞栞、弥月。岁己替换施术者，栞栞替换受困对手，弥月替换结界外对手。图片定义脸、发型、衣装及身形；视频定义运动及机位。
3. 制作无声白底运动布局：灰度 → CLAHE（clip 2、8×8）→ 高斯模糊（5×5、sigma 1）→ Canny（30/85、L2）→ 2×2 椭圆膨胀 → 反相。清掉底部字幕区域。删除原演员的身份细节、脸和服装，只保留必要的手势、环境结构及运动。按镜头编写遮罩，不能照搬另一招式的坐标。
4. 两个认可版本的区别：角色重绘版仅把首尾脸降为中性头部，仍残留中段原演员轮廓；三角色替换版进一步删除中性占位头及对手轮廓，因此身份更准确。局部遮罩也会损失邻近手掌细节，需要提示模型补全。
5. 提示词开头明确「最终输出完整上色的精细赛璐璐动画」。人物、手掌、手臂、地面及背景都要实心色块、材质、体积、明暗阴影和高光。明确白底线稿只是动作布局，擦除区域必须补画演员，不能作为白洞、线框或占位头输出。
6. 写出所有镜头的演员映射，特别约束开场、末帧、背影。逐项描述发型、眼睛、帽子、光环、衣服和少女比例，防止原演员脸/男装混入。按源片实际切点写时间表，不凭想象重排动作。
7. 日语音轨单独制作：岁己真实录音用于声色，新的日文示范用于发音。明确汉字及假名、停顿、重音、情绪和喊招时间，配嘴型及动作音效。原动作布局没有原片音轨。其他角色不说话。
8. 即梦采用 `seedance_2.0_fast_vip`、`m2v`、720p、16:9、15 秒、单产物。引用顺序是三张角色图 → 动作视频 → 日文示范 → 岁己声音。两个认可版本各报价 180 积分。
9. 保存稳定节点/提交身份，保存草案并回读引用，报价后按授权上限提交一次。超时继续查同一提交，不重复投单。每个新招式单独建账；失败退款无账单佐证时不抵扣保守占用。
10. 下载后检查文件、SHA256、参数、完整解码、包含真实末帧的接触表及整段播放。检查上色、所有角色、手势、镜头次序和空间展开；用日语 ASR 辅助确认台词。ASR 不能证明音色、情绪或自然程度，最终需要听感评价。

## 经验及限制

原片直接输入、变色模糊版遇到平台版权限制；白底运动布局两版成功，但多项处理同时变化，不能断定某一步导致审核结果，也不能保证后续片段可用。黑底细线版本容易生成发光线框，需加强全彩实体要求。火柴人姿态遗漏微型手、巨大手掌等领域主体，不适合本例。生成仍可能偏离手部细节或对手位置，认可版本原文件应保留不覆盖。

## 后续招式

无量空处沿用身份/动作分离及全彩要求，重新选择源片及编写逐镜头遮罩，保留交叉手指结印、面部特写与无限空间展开。日语为「領域展開……無量空処！」，读作「りょういきてんかい……むりょうくうしょ！」。独立记录本轮 600 积分上限。

## 伏魔御厨子实验（2026-10-15）

本轮独立上限600，报价累计288：11秒首版132、2K结印关键帧0、15秒修订156。素材及精确流程在 `outputs/sui-shrine-jp-20261015/`。小红帽岁己、原作神龛动作布局、日语「ふくまみずし」。修订结合先生成的全彩结印图，最后4秒增加环境斩击，推荐本地完整日文配音版 `full_v2_dub.mp4`。

极暗低分辨率源片直接提边容易丢空；提亮暗部又会放大压缩方块，模型可能把它们画成发光建筑。修订清空前段噪声，用文字补全环境，只保留后段干净结印和神龛布局，并加入全彩角色关键帧。建筑实体和帽子稳定性改善，但手印仍偏合十、神龛骨牙被简化。图像参考也必须目检，不能假设生成的手势正确。原生音轨首版喊招较完整，修订却读错，需分别检查；本地补配音时保留原版，校验视频流未改变，不把ASR当听感验收。

### 后续可复用的操作顺序

1. **先选动作，再读真实时长。** GIF逐帧累计延时，视频读取流信息；保存接触表并标出结印、喊招、对手反应和环境展开的切点。优先让成片长度接近参考，避免无意延长静态特写。
2. **先画一个真正可用的动画帧。** 用角色图保持帽子、发辫、眼睛、衣服与光环；构图包含清楚的手势和运动方向。单写「厉害原画师风格」不够，需明确粗细不均的墨线、有限色阶、硬边阴影、哑光衣物和笔刷背景，并检查成图是否仍像精细游戏插画。
3. **把三种参考职责写开。** 画风图定义最终上色和线条，角色图补充身份，视频定义动作与镜头。白底布局只是中间参考，空白区必须重绘全彩实体。清除原角色身份时保住关键手势，逐镜检查对手、背影和末帧。
4. **把运动要求写成时间表。** 明确切点、实际肢体动作、影浪方向、对手反应和结束构图；限制脸部特写停留时长。拖影、透视和停顿服务于可读动作，不能靠闪光或镜头平移代替运动。
5. **每个版本独立验收日语。** 同时提供招式汉字、假名读音、参考音频、喊招时间和表演指令。原生音轨读音成立时优先保留同期效果；确需补配音时另存文件，记录被静音的效果区间，并核对视频流哈希不变。ASR只辅助核对读音，不证明声线还原与情绪到位。
6. **先验收，再决定是否继续花积分。** 完整解码、检查包含真实末帧的接触表、浏览器播放到结尾；记录角色、手势、材质、镜头与语音的剩余问题。一次修订已有明确收益即可交付比较，不为花满上限而追加生成。保留精确提示词、引用、提交身份、文件哈希和报价记录。

### 参考与演出的取舍

- **GIF时间要逐帧累计。** 三份源素材实际时长为25.47、8.74、12.19秒。熔岩片段选0–3秒及13.5秒至结尾，段内保持原速，运动参考约14.96秒；海岛和法庭转为24fps后约8.75、12.21秒。不能把GIF帧数除以默认帧率当真实时长。
- **源片没有的动作要明确标为新编。** 海岛参考主要提供门口、海水和环境运动，结印与结尾鱼形式神由提示词另行设计；不能宣称整段复现了原作。清除角色身份的布局也会改变肢体信息，需检查生成的手势、人数和对手位置。
- **画风成立不等于动作成立。** 全彩粗线、硬边阴影和哑光衣物能保持角色辨识度，但仍要看实际动作变化。法庭版本有明确落槌，远景却出现额外小人物；将这类残留问题记入本地验收，不只保存最好看的关键帧。
- **发音示范也需要独立检查。** 仅有汉字、假名和声线参考仍可能读错；极短招式也容易被ASR识别成同音常用词。尝试整句和不同拼写后再决定补配音，不能用期望文本反向证明读音正确。一次本地试验把日语表演指令也读进了输出，因此指令语言、正文、种子及ASR结果都要留档。

### 让定格有明确的收束感

合集每招只选一条认可版本，避免重复候选稀释节奏。原始文件保留，统一输出1280×720、24fps、48kHz立体声。每段最后一个实际画面额外延长30帧（1.25秒），人物定格，镜头每秒缓推约2.8%，叠加衰减抖动、短促亮闪、漂移光点和滑入招式名，末尾约0.17秒淡出。另加本地合成的低频冲击、空气尾音和轻微余响，并让原音轨收尾淡出。

不能只检查播放器是否有声音或文件是否能打开。应逐一抽取七段定格开始、中间和结尾，检查画面变化及音频能量；对整片完整解码，核对章节时间、总帧数、输入和输出哈希，再在浏览器从头播放至结束。音频能量检查只能证明有信号，ASR只能辅助核对台词，二者都不替代听感验收。章节记录分别保存原文件路径和剪辑后路径，避免合成记录覆盖来源身份。

本轮合成为104.75秒视频、2514帧，七段末尾均保留1.25秒定格。三条新作另存本地配音版，校验压缩视频流哈希与原版相同：熔岩和海岛替换前4.6、4.5秒音轨，也会移除这些区间的原生音效；法庭版因后段疑似残留错读台词，替换整段音轨并重做空间冲击、金属余响和约10.95秒落槌音效。法庭独立招式示范ASR为「ちゅうぶく、しっし」，混音后识别为同音常用字，仍需听感确认停顿、声线与情绪。原版、补配音版和混音参数均保留，不把识别结果写成已完成听感验收。
